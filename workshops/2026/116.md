## Abstracts

### Pabst: Annotate your TypeScript and find bugs!


Property-based testing is an approach to software testing in which one validates a program against properties
it is intended to have. Sorting an array, for instance, ought to be an idempotent operation, which can be easily
expressed as a universally quantified logical statement. [Pabst](https://github.com/jessealama/pabst) is a tool
for annotating pieces of TypeScript programs with properties. It is effectively an alternative front-end to
Nicolas Dubien's [fast-check](https://fast-check.dev/), but restricted to TypeScript programs annotated,
with JSDoc-style comments, in its own little language for properties. When Pabst runs, it attempts to find
counterexamples to the asserted properties. Pabst has found a number of bugs, even in programs that had 100%
unit test coverage, thereby enabling TypeScript programmers to experience the
[unreasoanble effectiveness of property-based testing](https://proofsandintuitions.net/2026/05/18/property-based-testing-specifications/).
